## Why

登录后直接进入项目列表页缺乏全局视图，用户无法快速了解自己的工作全貌。同时系统缺少后台管理入口，管理员无法在系统内管理用户。需要补充 Dashboard 主页和用户管理功能，形成完整的后台管理系统体验。

## What Changes

- **新增 Dashboard 主页**：登录后默认展示主页，包含项目统计卡片（总数/草稿/审批中/已通过/已驳回）、最近项目列表、快捷操作（新增项目）。主页为永久标签，不可关闭。
- **新增系统管理菜单**：左侧菜单栏增加「系统管理」一级菜单，仅 ROLE_ADMIN 可见，下设「用户管理」二级菜单。
- **新增用户管理功能**：用户列表页展示所有用户信息，支持搜索、分页；操作列包含查看、编辑、删除、重置密码图标。
- **新增用户详情页**：只读展示用户信息及所属角色。
- **新增用户编辑页**：支持修改用户信息和分配/移除角色。
- **新增重置密码功能**：弹窗输入新密码，BCrypt 加密后更新。
- **Header 新增用户下拉菜单**：标签栏右侧展示当前登录用户名，下拉包含「用户信息」（跳转个人资料页）和「退出/切换账号」（注销并返回登录页）。
- **标签系统增强**：支持永久标签（closable=false），关闭操作跳过永久标签。

## Capabilities

### New Capabilities
- `dashboard-home`: Dashboard 主页，展示项目统计、最近项目、快捷操作
- `user-management`: 用户 CRUD 管理（列表/详情/编辑/删除/重置密码）
- `user-profile`: 用户个人信息查看与退出登录
- `tab-enhancements`: 标签系统支持永久标签和用户下拉菜单

### Modified Capabilities
- 无

## Impact

- **后端**: 新增 `/api/pm/charters/stats` 接口；扩展 `SysUserController` 增加用户 CRUD 和重置密码接口
- **前端**: 新增 Dashboard 页面、用户管理页面（列表/详情/编辑/个人资料）；更新路由配置、侧边栏菜单、主布局 Header、Tab Store
- **数据库**: 无 DDL 变更
