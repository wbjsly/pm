# WH 管理系统

WH 管理系统是一个统一的企业资源管理平台（ERP），涵盖项目管理、预算管理、工时管理、成本管控、审批流程及系统管理等核心业务功能，旨在为企业的项目交付和资源规划提供一体化的数字化管理工具。

## 技术架构

### 后端技术栈

| 组件 | 技术 |
|------|------|
| 框架 | Spring Boot 2.7.18 |
| 语言 | Java 11 |
| ORM | MyBatis Plus 3.5.5 |
| 工作流引擎 | Flowable 6.8.0 |
| 数据库 | SQLite 3（嵌入式，无需外部数据库服务） |
| 连接池 | Alibaba Druid 1.2.20 |
| 安全认证 | Spring Security + JWT |
| API 文档 | Knife4j (Swagger) 4.3.0 |
| 对象存储 | MinIO 8.5.7 |
| 工具库 | Hutool 5.8.25 |
| 缓存 | Redis 7.x |

### 前端技术栈

| 组件 | 技术 |
|------|------|
| 框架 | Vue 3.4.21（Composition API） |
| 构建工具 | Vite 5.2.0 |
| UI 组件库 | Element Plus 2.6.1 |
| 状态管理 | Pinia 2.1.7 |
| 路由 | Vue Router 4.3.0 |
| HTTP 客户端 | Axios 1.6.7 |

### 架构模式

采用分层架构：`Controller → BO（业务对象） → DAO → Entity`，前端采用组件化设计，通过 Axios 与后端 REST API 通信。数据库采用 SQLite 嵌入式文件数据库，无需安装外部数据库服务，支持 WAL 模式提升并发性能。

### 业务需求

1. **项目立项规范化**：建立标准的项目立项流程，从项目章程创建、审批到归档，确保每个项目有明确的范围、目标、预算和干系人
2. **预算精细化管控**：实现预算编制、审批、执行、对比的全流程管理，支持多级科目分解、版本控制和成本预警
3. **工时高效管理**：提供直观的日历化工时填报界面，支持多项目工时记录、审批流和统计分析
4. **成本实时监控**：自动监控预算执行进度，按阈值分级预警（80%/95%/100%），及时识别超支风险
5. **WBS 工作分解**：遵循 PMBOK 100% 规则，支持树形 WBS 分解、版本管理、优先级排序和导入导出
6. **产品主数据管理**：建立产品与模块的统一管理，与 WBS 和成本体系联动
7. **权限与审批**：基于 RBAC 模型的权限控制，结合 Flowable 工作流引擎实现灵活的审批链

## 功能清单

### 1. 项目立项（Project Charter）

- 项目章程创建（自动生成章程编号 `CHARTER-YYYY-NNN`）
- 项目基本信息：名称、编号、简称、描述、范围概述、项目分类
- 合同信息管理：合同编号、含税/不含税产值、税率、税额自动计算
- 项目发起人、项目经理指派
- 项目目标与衡量指标
- 关键干系人管理
- 预算上限设置
- 审批流程：草稿 → 审批中 → 已通过/已驳回 → 已关闭
- 审批后自动生成 WBS 顶层元素

### 2. WBS 管理（工作分解结构）

- 树形结构 WBS 分解，自动编码（1.0 → 1.1 → 1.1.1）
- 最多支持 4 层分解
- WBS 元素属性：名称、编码、类型、工作量估算、预算估算、优先级、技术难度、计划日期
- 关联产品与模块
- **100% 规则校验**：父节点工作量 = 所有子节点工作量之和
- 版本管理：每次变更生成新版本，保留历史追溯
- 暂停/恢复功能：暂停期间无法编辑
- 状态管理：计划中、进行中、已完成、已暂停
- 导入/导出（Excel）

### 3. 预算管理

- **预算科目体系**：人工、采购、差旅、商务费用、客户招待费、活动费、其他
- **人工预算**：岗位角色 × 工时 × 成本定额
- **采购预算**：BOM 项 × 数量 × 单价
- **预算版本控制**：
  - 语义化版本号：v0.1（草稿）→ v0.7（审批中）→ v1.0（已审批）→ v1.1（调整）
  - 已审批状态的预算不可直接编辑，需创建新版本
- **预算 = 分项汇总 + 管理储备**
- 审批流程集成
- 预算与 WBS 数据联动
- 预实对比视图：预算 vs 实际成本

### 4. 实际成本

- 成本类型：人工、材料、设备、其他
- 关联预算明细项，自动更新预算项的实际成本
- 计算成本差异和偏差率
- 支持按项目、成本类型、日期范围查询

### 5. 成本预警

- 定时任务每日 6:00 自动巡检（项目已立项 + 预算已审批）
- 三级预警阈值：
  - INFO（黄色）：执行率 ≥ 80%
  - WARN（橙色）：执行率 ≥ 95%
  - CRITICAL（红色）：执行率 ≥ 100%
- 不同级别对应不同的结案关闭权限
- 预警 Dashboard 展示

### 6. 工时管理

- 日历视图工时填报（周日历格式）
- 单日多项目工时记录
- 工时状态：草稿、已提交、已审批、已驳回
- 颜色标识：黄色（草稿）、绿色（已审批）、红色（已驳回）
- 校验规则：不能填报未来日期、单日工时 ≤ 24 小时
- 工时审批流程
- 工时日历配置：工作日、周末、节假日

### 7. 产品与模块管理

- 产品主数据：编码、名称、状态、版本、上架日期
- 产品模块管理：编码、名称、状态（启用/停用）、版本、上架日期
- 产品与模块的一对多关系
- 与 WBS 元素关联

### 8. 系统管理

- 用户管理：增删改查、密码重置、状态管理
- 角色管理：内置 8 种角色（ADMIN、PM、SPONSOR、BA、ARCH、QA、DEV、IMPL）
- 权限管理：基于 RBAC 模型，菜单级权限控制
- 用户角色分配、角色权限配置

### 9. 审批引擎

- 基于 Flowable BPMN 引擎
- 通用审批完成回调机制（`ApprovalCompletedCallback` 接口）
- 支持多种审批流程：项目章程审批、预算审批、工时审批等
- 审批实例和审批记录全量追踪

### 10. 文件存储

- MinIO 对象存储集成
- 支持文件上传、下载
- 可配置 endpoint 和 bucket

## 快速启动

```bash
# 启动前后端（根目录）
npm run dev

# 单独启动
npm run dev:fe    # 前端（端口 4175）
npm run dev:be    # 后端（端口 8080）

# 数据库迁移
npm run dev:db:migrate
```

## 数据库约定

- 主键：UUID（32 位字符串）
- 逻辑删除：`del_flag`（'0' = 正常，'1' = 已删除）
- 审计字段：`create_by`、`create_date`、`update_by`、`update_date`
- 乐观锁：`ver_no`
- 命名规范：表名 `lower_snake_case`，列名 `UPPER_SNAKE_CASE`
